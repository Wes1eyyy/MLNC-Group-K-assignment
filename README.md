# Premier League Data Analysis Project

This project involves scraping, cleaning, and analyzing Premier League data. The `scraping_data.ipynb` notebook is responsible for collecting the necessary data.

## Data Directory

The `data/` directory contains all the datasets used in this project. These files are generated by the `scraping_data.ipynb` notebook.Which context is identical with Section 1.3 in the ipynb file that we submitted.

### Getting Started

**Important**: The data scraping process in `scraping_data.ipynb` can take several hours to complete. To save time, you can use the pre-scraped files located in the `data/` directory. By downloading and placing the `data` folder in your project's root directory, you can skip the scraping and data merging steps and proceed directly to the analysis and modeling parts of the project (e.g., Section 3).

### Purpose of Data Collection

The primary objectives of the data scraping process are to:
- Collect historical team player ages from Transfermarkt (2000-2025).
- Collect historical team player market values from Transfermarkt (2000-2025).
- Collect the latest EPL match data from football-data.co.uk.

### Data Files

The `scraping_data.ipynb` notebook generates the following files, which are included in the `data` directory:

*   `premier_league_team_ages_2000_2025.csv`: Contains the average and total age of players for each Premier League team, for each year from 2000 to 2025. This data is scraped from Transfermarkt.
*   `premier_league_team_values_2000_2025.csv`: Contains the total and average market value of players for each Premier League team, for each year from 2000 to 2025. This data is also scraped from Transfermarkt.
*   `epl-latest-2025.csv`: Contains the latest EPL match data scraped from football-data.co.uk. This data is intended to be merged with the training data.

The directory also contains the primary datasets for training and testing:
*   `epl-training.csv`: The main dataset for training models.
*   `epl-test.csv`: The dataset used for testing the models.
